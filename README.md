# WordPress服务器配置：从1核1G能不能跑，到宝塔装LNMP、伪静态和SSL一次配到位

搜「WordPress服务器配置」的人，通常已经准备下单了，只是不确定该点哪个按钮。1核1G 到底行不行？PHP 装 7.4 还是 8.2？宝塔面板弹出来的「推荐安装套件」选 LNMP 还是 LAMP？

这些问题没有玄学答案，但它们真的决定你的站是「能打开」还是「打开要等三秒」。下面按顺序拆：WordPress 吃哪些资源、配置怎么按站点类型挑、环境走哪条路装、装完之后哪几个设置必须动。

## WordPress 到底吃掉了服务器的什么

先说硬指标。WordPress 官方现在的建议是 PHP 7.4 及以上、MySQL 5.7 或 MariaDB 10.4 及以上，并且要求 HTTPS 支持。这是「能跑」的底线，不是「跑得动」的底线。

真正的瓶颈顺序是这样的：

**内存排在第一位。** 一个 WordPress 进程跑起来占用不大，但现场通常不止一个进程。PHP-FPM 会预开几个 worker，MySQL 自己也要常驻几百 MB，宝塔面板本身还要吃掉一部分。再随便装两三个插件——缓存、SEO、安全类——内存就见底了。1G 内存跑 WordPress 不是不行，是留给你的余量太少，一次插件更新或者一次爬虫扫站就可能把 MySQL 顶到 OOM。所以主流建议是 2G 起步。

**硬盘看的是类型不是容量。** WordPress 本体只有几十 MB，数据库在小型站点也就几百 MB。真正影响体验的是随机读写能力，机械盘和 NVMe 的差别在后台发文、装插件时会直接体现出来。容量反而不是问题，图片和备份才是长期吃盘的东西，这部分可以后期加。

**CPU 在被缓存挡住之后才重要。** 静态缓存命中率高的时候，CPU 基本闲着；一旦缓存没生效（比如后台、搜索页、登录用户页），每个请求都是一次真实的 PHP 执行。所以低配机器的正确姿势是装缓存，不是加核心。

**带宽要看访问来源。** 面向国内访客，带宽小但线路好，比带宽大但绕一圈更舒服。这一点在选机房时会比在选配置时更影响结果。

## 按站点类型配，别按预算焦虑配

把 WordPress 的常见用法摊开，配置其实很好对应：

| 站点类型 | 建议配置 | 内存理由 |
| --- | --- | --- |
| 个人博客、图文站，日访问几百 | 1核1G～2核2G | 装好缓存后 1G 能跑，但插件要克制；2G 更从容 |
| 企业官网、小型资讯站 | 2核2G～2核4G | MySQL 常驻 + FPM worker + 面板，2G 是舒服线 |
| 内容量大、插件多、含会员或商城 | 2核4G～4核8G | WooCommerce 这类插件会显著抬高内存和查询量 |
| 日 PV 上万、有明显并发 | 4核8G 起，配对象存储 | 瓶颈转移到数据库和出站带宽 |

一个经常被忽略的分界线：**如果你打算大量使用可视化编辑主题、动效主题或者商城插件，配置直接往上跳一档**。这类主题会额外加载大量 CSS/JS，插件又会拉高内存占用，1核1G 配这类主题，后台点一下要转好几圈。

反过来，如果你的站就是纯文字、用轻量主题、开了页面缓存和 CDN，1核1G 加一块云盘能安稳跑很久。没必要为了「以后可能火」现在就买 8 核，WordPress 站点升级配置的成本远低于你一年白付的差价。

## 环境怎么装：两条路，选一条就行

**路线一：直接买预装宝塔面板的镜像。** 这是新手最省事的一种。雨云云服务器在下单时可以在系统选项里挑「预装宝塔面板」的镜像，机器创建完成后，控制台会直接给出面板地址、用户名和密码，不需要你自己 SSH 进去敲安装命令。少一步就少一个出错的地方。

**路线二：系统 + 手动装宝塔。** 选 Debian 或 Ubuntu 的干净系统，SSH 连上去跑一遍宝塔的官方安装脚本，装完同样会输出面板地址和初始账号密码。多花三到五分钟，好处是系统版本你自己心里有数。

无论哪条路，第一次登录面板都会弹出环境安装向导，这里的选择会影响后面所有事情：

- **Nginx**：WordPress 场景下的常规选择，伪静态规则现成，资源占用比 Apache 小。
- **MySQL 5.7 或 8.0**：5.7 兼容性最省心，8.0 性能更好但在老主题老插件上偶尔会撞编码问题。
- **PHP 7.4 或 8.x**：7.4 兼容面最广，8.1/8.2 性能和安全性更好，但年代久远的主题可能报错。拿不准就先 7.4，站点跑顺了再考虑升。
- **phpMyAdmin**：选上，改数据库的时候会用到。

装完这套环境通常要十几到二十分钟，期间别关浏览器也别去重启机器。

## 装完 WordPress 之后，必须动手的六个设置

环境装好只是及格。下面这些是新手最容易漏、漏了就要返工的：

1. **伪静态和固定链接要配套改。** 宝塔里给站点设置好 WordPress 伪静态规则，然后进 WordPress 后台「设置 → 固定链接」选「文章名」之类的结构。只改一边的结果是所有内页跳 404。
2. **数据库地址填 127.0.0.1。** 这是一个高频坑。如果用虚拟主机，雨云管理面板上显示的远程 MySQL 端口是给 Navicat 这类工具用的，网页程序里要填的是 `127.0.0.1`，端口 `3306`。
3. **域名要在两处都绑。** 宝塔里建站绑一次，雨云控制台的虚拟主机域名管理里再绑一次。漏掉第二处，站点就是打不开，而且报错信息不会告诉你原因。
4. **SSL 证书顺手申请。** 宝塔里可以直接申请 Let's Encrypt 免费证书，签发后打开「强制 HTTPS」。不装的话浏览器地址栏会显示不安全，跳失率和 SEO 都受影响。证书 90 天过期，记得把自动续签勾上。
5. **管理员账号别用 admin。** 这个不用多解释，暴力破解脚本第一个试的就是它。
6. **数据备份设成自动的。** 雨云的产品自带备份功能，可以设定时任务。WordPress 出问题最常见的原因就是手贱装了个不兼容的插件，有备份的话五分钟回滚。

如果是虚拟主机装的宝塔，还有一条：**别在面板里去升级或修复宝塔自身**。共享环境下的宝塔是特殊处理的，升级可能直接导致面板打不开，出问题要用雨云提供的修复功能。

## 机房怎么选，取决于你的访客在哪

这一步经常被跳过，但它对「网站快不快」的影响比 CPU 大。

- 访客主要在国内、且已有备案域名：选国内机房，网络质量最好。
- 访客在国内但没有备案、也不想备案：香港机房，延迟最低，线路通常三网直连。
- 大流量下载站、面向海外访客：美国洛杉矶的大带宽线路更划算，带宽给得多，延迟高一些。
- 需要住宅 IP、做跨境业务：可以考虑新开的韩国或德国节点，这类机房提供原生 IP 和住宅 IP 选项。

备案这件事要提前想清楚：国内机房做网站，域名必须先在阿里云之类的平台完成备案，这个流程按周算。如果不想等，就一开始直接选海外机房。

## 几个常见问题

**1核1G 到底能不能跑 WordPress？**
能。轻量主题 + 页面缓存 + 缓存插件，个人博客完全够用。但它没有余量，装三四个插件就会开始吃紧，后台操作也会变慢。预算允许的话直接上 2G。

**选 Nginx 还是 Apache？**
WordPress 场景下 Nginx 更常见，资源和并发表现更好，伪静态规则宝塔里现成。Apache 的优势是 `.htaccess` 更灵活，但配置不当更容易出问题。

**国内机房一定要备案吗？**
要做网站的域名必须备案，这是硬性要求。备案周期按周算，且必须在有资质的平台完成。不想等就选香港或美国机房。

**虚拟主机和云服务器选哪个？**
只是跑一个 WordPress 站，虚拟主机够用而且便宜。要装 Java、Python 服务，要独立 IP，要折腾系统环境，就上云服务器。

**升级配置麻烦吗？**
雨云的套餐支持在控制台里直接升级，虚拟主机官方说法是一分钟内完成，云盘也能按天扩容。所以起步配置不必一步到位，按实际访问量加就行。
